# Worldbuilding Engine

管理世界观的**来源、状态、约束、真实性、依赖和路由**。完整世界设定工件由 `fiction-core-zh:world-architect` 创作；本技能只在 `seed` 档直接给最小候选，避免两套系统生成竞争版本。

## 按需读取

- 创建或扩展：`references/methodology.md`、`references/state-model.md`、`references/realism-audit.md`
- 审查或修复：`references/state-model.md`、`references/realism-audit.md`
- 持续多轮、候选积累或正史大量更新：再读 `references/iteration-protocol.md`
- 人物、故事、细纲、正文或编辑：再读 `references/fiction-core-routing.md`
- 自动化、数据契约或 MCP：再读 `references/mcp-contract.md`；状态字段以 `references/world-state.schema.json` 为准
- 范例作品技法：联用 `$distill-novel-craft`，但把结果交回实际工件所有者

先读取用户给出的 Vault、Wiki、仓库或附件及其项目规则；项目规则高于本技能默认值。

## 不变量

1. 自动补全只能是 `draft`／`proposed`；只有用户明确采纳的原子主张才能成为 `canon`。价值、主题、核心谜底和不可逆决定可标 `author-required`。
2. 分开作者真相、世界内理论、公众认知和读者未知；不知道就保留不知道。
3. 可重复能力必须有输入、输出、成本、损耗、故障、维护、权限、痕迹和反制；普及后必须影响劳动、组织、利益和规避。
4. 真实性允许偏离现实事实，但因果、社会和体验必须成立。机器验证只证明已记录的结构与证据，不证明文学质量。
5. 审查默认只报告；用户要求创建、修复或写入时才修改文件。写入候选不等于晋升正典。
6. 上游变化必须标记受影响下游；不得用正文补丁掩盖世界或架构问题。

## 最小充分深度

- `seed`：一句灵感或第一轮方向。给 1 个推荐候选、最多 2 个备选、3—7 条规则原子、一条后果链、一个生活切片、最高风险缺口和下一路由；不为流程新建文件。
- `candidate`：系统完善、长期项目或人物／故事准备。建立状态、规则账、相关社会循环、情境证据、审计和下游状态。
- `instance`：完整地区、文明、制度、主线舞台或正典晋升。闭合同一人口、地图、资源、设施、法域、家庭和时间线，并运行项目门禁。

边界不清时从 `seed` 开始；持续多轮只是迭代方式，不是更深档位。

## 工作流

1. **定权威**：识别当前事实源、只读区、正典、候选、决策记录和验证入口。多页冲突按“最新明确裁定 → 当前总入口／索引 → 领域权威页 → 候选页”解释。
2. **压种子**：提取核心奇异点、体验承诺、尺度、视角、已锁定内容和不可擅定内容；能安全推断的直接写为候选，不把框架变成问卷。
3. **立规则账**：写清 `capability`、`impossibility`、资源账、故障和知识层。只有复杂概念、历史分叉、相似体系或认知误读会改变设计时，才增加紧凑的概念边界、历史分层、关系裁定和认知生态。
4. **推后果**：至少走通“规则 → 资源／代价 → 技术／设施 → 劳动／组织 → 权利／分配 → 日常／文化 → 冲突 → 历史反馈”。优先复用既有机制；缺口明确标记，不用新专名填空。
5. **落地验证**：`seed` 给一个普通人生活切片；`candidate`／`instance` 再检查普通日、短期故障和代际后果。通用框架明显领先实例时停止横向扩写，改做一个共享地图、机构、家庭和时间的纵切。
6. **审计与路由**：有状态文件时运行 `worldbuild.rb validate`、`audit`、`route`；只读或无状态任务做同字段语义审查，并记录 `machine_audit: not-run`。完整世界工件交给 `world-architect`，完成后由本技能复审并更新依赖失效。

只有用户明确采纳后，才按项目协议执行 `proposed → canon`。部分采纳只晋升被点名的原子主张；旧记录保留形成史。

## 交付

先给可读候选，再给紧凑状态：

- 已锁定、候选、待作者裁定；
- 实际修改文件；
- 审计结果、最高风险缺口和失效下游；
- 下一路由；持续项目再附当前轮次与下一项最高收益纵切。

验收句：即使没有主角和作者救场，人物只掌握局部知识，这个世界仍会按同一规则消耗资源、组织劳动、制造差异、处理失败并留下历史。
