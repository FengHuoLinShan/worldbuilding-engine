# 真实性审计手册

## 1. 审计目标

审计不问“像不像现实地球”，而问：在项目自定规则下，世界能否持续产生相容的物质流、制度、生活、差异和历史。

最高验收是反事实承压：换主角、换地区、资源减半、技术普及十年、危机结束或坏人消失后，仍能推出相容但不必相同的结果。

## 2. 六个社会再生产循环

六环是乘法关系，不能互相代替。

| 键 | 循环 | 必须闭合的链 |
|---|---|---|
| `material` | 物质 | 取得 → 加工／运输 → 分配／消费 → 废物／热／磨损 → 维护／回收／污染 |
| `population_care` | 人口与照护 | 出生／进入 → 抚育／教育 → 劳动／成家 → 疾病／残障／照护 → 衰老／死亡／继承 |
| `economic` | 经济 | 劳动 → 收入／资源／权利 → 消费／储蓄／债务 → 资产与机会转移 → 新阶层位置 |
| `institutional` | 制度 | 制定 → 解释／执行 → 服从／规避／争议 → 利益重分布 → 新规则联盟 |
| `knowledge` | 知识 | 观察 → 记录 → 验证 → 分类 → 教授／传承 → 应用 → 纠错 |
| `meaning_identity` | 意义与身份 | 命名 → 分类 → 仪式／叙事 → 身份／边界 → 荣誉／羞耻／归属 → 下一代正常观 |

每环至少记录 `chain`、`evidence`、`gaps` 与覆盖状态。

## 4. 五条耦合链

### C01 权利链

```text
权利主体 → 义务承担者 → 预算 → 人员／设施 → 资格证明
→ 拒绝与申诉 → 等待期间生存 → 错误责任
```

### C02 技术链

```text
发明 → 制造 → 认证 → 购买／获准 → 操作 → 维护 → 事故责任
→ 备件／废物 → 漏洞利用 → 被淘汰者
```

### C03 身份链

```text
产生 → 记录 → 法域承认 → 转移／撤销 → 申诉／退出
→ 失踪／死亡处理 → 是否代际继承
```

### C04 证据链

```text
事件 → 观察者／仪器 → 记录 → 保管 → 缺失／伪造可能
→ 法律解释 → 专家可达性 → 证明失败承担者
```

### C05 分配链

```text
能力存在 → 地理可达 → 设施覆盖 → 经济可负担 → 身份有资格
→ 语言可理解 → 技能会使用 → 社会允许 → 出错有救济
```

## 5. 成熟度 L0—L6

| 级别 | 可证明的内容 |
|---|---|
| L0 命名 | 有概念或机构名 |
| L1 功能 | 知道它做什么 |
| L2 机制与限制 | 知道需要什么、何时失败、不能证明什么 |
| L3 资源与分配 | 知道谁出钱、谁维护、哪里可达、谁被排除 |
| L4 制度与争议 | 有多法域、裁量、申诉、责任和利益冲突 |
| L5 历史与日常 | 知道为何形成，人们怎样准备、抱怨、绕路、互助和生活 |
| L6 反馈与演化 | 能推出职业、黑市、运动、改革、反改革和新不平等 |

通用框架与地区实例分开评级。`framework: 6, instance: 0` 表示问题清单很成熟，但世界里还没有一座可运行的地方。

## 6. 十二项压力测试

| ID | 测试 | 验收问题 |
|---|---|---|
| T01 | 主角移除 | 主角从未出生，冲突和历史是否仍成立？ |
| T02 | 普通星期二 | 普通家庭从早到晚怎样生活？ |
| T03 | 一生 | 从出生到死亡经过哪些身份、服务和义务节点？ |
| T04 | 最贫者 | 没钱、证件、关系和时间的人怎样获得最低生存？ |
| T05 | 上层例外 | 富人买到的是资源、等待、可信度、冗余，还是违法豁免？ |
| T06 | 一项权利 | 谁负责、谁出钱、怎样证明、怎样申诉？ |
| T07 | 一件商品 | 原料、劳动、运输、储存、消费、废弃能否走完？ |
| T08 | 故障与维修 | 关键设施停机七天，谁先受害、谁召回、谁获利、谁担责？ |
| T09 | 跨境 | 普通人带家庭、财产、技能和伤病跨法域时失去什么？ |
| T10 | 历史来源 | 荒谬制度为何出现、为何没有被废除？ |
| T11 | 集体行动 | 没有天命领袖，人们怎样跨过互不信任与先行动风险？ |
| T12 | 十年后 | 新能力普及十年后产生哪些职业、骗局、阶层和反改革联盟？ |

## 7. 审计顺序

1. **结构门**：状态可解析、ID 唯一、依赖可寻址；
2. **本体门**：核心规则同时有允许／禁止、账本、失败、维护；
3. **知识门**：真相、理论、信念、角色与读者边界不串层；
4. **社会门**：六环、二十二面、五链有证据和明确缺口；
5. **体验门**：普通日、危机、一生／十年反馈能落到身体与时间；
6. **历史门**：制度和设施有形成、事故、补丁、既得利益与演化；
7. **反事实门**：十二项测试暴露规则是否依赖主角或作者方便；
8. **叙事门**：人物选择来自系统压力，而非替设定做讲解。
9. **饱和门**：继续补框架是否仍会改变场景、选择、依赖或采用判断；若不会，转向纵切或收敛。

### 三项纵向附加测试

- **扩散梯度**：能力存在、训练连续、民生覆盖、冲突改式分别到哪一层；不以“会用”替代“会教、会维护、可普及”。
- **最高级可证伪**：对唯一／最发达／最开放写出比较范围、操作判据、知识层和可能反例。
- **时间尺度惯性**：十年内哪些骨架相对稳定，百年内哪些必然换形，变化由何种设施、资本、地权、人口与代际载体推动。

## 8. 正史全量交叉审计

当正史经历集中采用、多个地区／国家／势力合并，或用户要求整体协调时，不能只抽查底层规则。先按“最新明确裁定 → 当前正典总入口／索引 → 领域权威页 → 候选页”建立逐主张差异账；日期变更记录、旧审计报告与日志切片只保留形成史，不因措辞更完整而覆盖当前裁定。

每个主要地点、国家、组织、事件和跨域能力至少检查五面：

1. **权威状态**：已采用事实是否仍被现行页称为候选；开放精度是否被反向写死；旧页是否被误当当前入口。
2. **历史因果**：成立、分裂、迁徙、事故和改革是否有当时必要性、物质／组织载体与当代遗产；后来的结果不得倒写成唯一原因。
3. **交流与扩散**：人员、货物、文本、教师、凭证和制度分别需要多少时间、节点、翻译、互认与维护；能传到不等于能理解、采用、执行或普及。
4. **势力关系**：组织的主体、事项、地域、财源、期限、退出和争议机制是否明确；共享标准或临时合作不得偷换成统一政府、永久主权或天然代表权。
5. **导航与影响**：总入口、实体索引、依赖图、变更记录和下游审查是否覆盖新正典；历史记录不回写，当前入口不得漏项。

每项结论只使用：`KEEP` 保持、`SYNC` 同步修复、`CANDIDATE` 降为候选、`AUTHOR-REQUIRED` 作者裁定、`OPEN` 继续开放。先修会让当前读者误判权威或因果的主张；纯措辞差异和仍能安全承载未来故事的空位不扩写。

## 9. 风险分流

发现问题时用以下动作，而不是一律补写：

- `CLOSE`：现有规则可直接闭合，且不改变作者意图；
- `SPLIT`：表层说法、世界内理论和作者真相混在一起，需分层；
- `KEEP-GATE`：未知本身有价值，但要设置边界和进入剧情前的门；
- `CANDIDATE`：给出一至三个可比较候选，不写成正典；
- `AUTHOR-REQUIRED`：涉及核心主题、不可逆选择或项目未授权决定，交还用户。

## 10. 审计输出

不要只给总分。最低输出：

- 当前最高可证成熟度，通用／实例分列；
- 阻断项：会让后续故事失真的缺口；
- 高收益补强项：一处补全能闭合多个链条；
- 保留矛盾：真实的利益、认知或历史冲突；
- 待作者裁定；
- 建议下一技能和理由；
- 每项结论的证据路径。
- 全量交叉审计再给权威差异账，以及历史、交流、势力关系和索引／依赖五面的结论。
- 持续项目再给一个下一轮纵切、候选山状态与全量检查点是否到期。
